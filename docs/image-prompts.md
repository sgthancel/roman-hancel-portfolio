# Project Card Image Prompts

AI image prompts to replace the screenshot thumbnails on the portfolio's project cards.

## How to use

- **Size:** cards render at 350×200 with `object-cover`, so generate at **16:9 (e.g. 1600×900)**. Keep the subject centered; the edges may crop slightly.
- **Format:** export as `.jpg` (or `.webp`) and save to `public/images/` using the filename listed under each project. Existing filenames are reused so the code only needs changes for cards that don't have an image yet.
- **Shared style:** every prompt ends with the same style line so the set looks like one family. It matches the site's handwritten Caveat headings and the parchment profile portrait. Swap it out in all prompts at once if you want a different look.
- **Links:** each prompt opens with the live URL. If your generator can browse (ChatGPT, Gemini, etc.), it can visit the site for color and branding cues. If it can't, the prompt still works by itself.
- **No text in images:** AI generators garble lettering, and the card already shows the title. Every prompt asks for no words or logos.

> **Shared style line** (already included in each prompt below):
> *Hand-drawn ink linework with soft watercolor washes on warm cream parchment paper, subtle paper texture, a muted palette with one confident accent color, gentle depth, editorial illustration quality, 16:9, no text, no letters, no logos, no UI screenshots.*
